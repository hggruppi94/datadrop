## 🚀 What It Does

DataDrop turns any CSV file into an interactive dashboard — instantly, in your browser. Just drag and drop.

## ✨ Features

- **📈 Auto-detect column types** — numbers, dates, and text identified automatically
- **📊 Smart chart generation** — line, bar, pie, and scatter charts based on your data shape
- **🔍 Interactive filters** — dropdown filters for text columns + full-text search
- **📋 Sortable data table** — click any header to sort, paginated for large datasets
- **📊 Column insights** — min, max, average, unique counts at a glance
- **📥 CSV export** — download your filtered data
- **🎮 Sample data** — "Try with sample data" button for instant demo
- **🔒 100% client-side** — zero data transmitted, everything runs in your browser
- **🌙 Dark mode** — easy on the eyes
- **📱 Responsive** — works on desktop and mobile
